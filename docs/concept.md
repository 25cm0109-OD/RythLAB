# RythLAB（リズラボ）企画

音楽ゲーム（音ゲー）の楽曲に特化した音楽アプリ。卒業制作だが、小規模に収めず本気の規模・品質で作る。

## 企画の柱
1. **ショート動画式再生**: 縦スワイプで次々に曲を再生する
2. **ライブ会場の部屋（同期再生）**: 部屋に集まった人と同じ曲を同期して聴く
3. **プレイリスト**: 曲を集めて自分用のリストを作る

## 開発方針
- 開発期間は約4ヶ月（11月〜2月）
- AI開発をフルで使う（Copilot CLIに指示を出して実装）
- 設計から入る（UI設計は後）
- DB（Firebase/Firestore）から先に進め、動作確認は最初は簡易的なWeb UIで行う
